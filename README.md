# Cinema Intelligence

롯데시네마 예매순 TOP 10 영화의 공개 관람평 541개 분석을 담은 18장 HTML 슬라이드 덱.

정적 HTML/CSS/JavaScript, 외부 라이브러리 없이 동작합니다. index.html을 브라우저에서 열거나 GitHub Pages로 배포할 수 있습니다.

- 방향키·Space: 이동, G: 목차, N: 발표자 노트, F: 전체 화면
- 주제 히트맵: 리뷰 수/비중 전환, 그래프: 툴팁
- 인쇄: 슬라이드별 PDF 저장 가능
- prefers-reduced-motion 지원

분석은 최신순 편의 표본 및 표현 사전 매칭입니다. 평점·전체 관객 만족도를 추정하지 않습니다. 출처와 한계는 덱에 명시했습니다. 공개 저장소에는 집계 데이터만 포함하고 .env와 원본 관람평 HTML은 제외합니다. 이미지 에셋은 GPT 이미지 생성 도구로 만든 콘셉트이며 실제 영화 장면·공식 시설 사진이 아닙니다. 생성 프롬프트는 assets/prompts.md를 참고하세요.
